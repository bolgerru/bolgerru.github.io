# bolgerru.github.io

Personal site of Russell Bolger. Plain HTML, CSS and a little JavaScript: no build step.

- `index.html` - the page
- `assets/style.css` - all styling; colour tokens at the top, dark and light themes
- `assets/main.js` - theme toggle, scroll reveals, count-ups, copy-email
- `assets/img/` - images, each as WebP with a JPEG fallback

Edit and push to `main`; GitHub Pages redeploys in about a minute.
